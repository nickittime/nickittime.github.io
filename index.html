kvlite

Key-value store in C++17

  • Source code
  • How it works
What
An in-memory store with least-recently-used eviction, keys that expire, and an append-only file that is replayed on restart.
How
A hash map plus a doubly linked list gives O(1) lookups and evictions. Log records are length-prefixed, and an incomplete last record from a crash is detected and cut off.
Proof
34 GoogleTest tests, including 20,000 random operations checked against a reference model. CI builds with GCC, Clang, MSVC, and AddressSanitizer.

  • CMake
  • GoogleTest
  • GitHub Actions

Freight Cost Watcher

Anomaly detection with a checked LLM

  • Source code
  • Run it without an API key
What
Finds unusual freight-cost rises across 7 Indian road corridors, both sudden spikes and slow cost creep, and checks each one against operations notes.
How
Rolling own-route and peer-route baselines with a hysteresis rule narrow 728 route-weeks to 22 candidates. An LLM proposes a cause for each, and five rule-based checks decide whether to accept it.
Proof
39 unit tests that run offline. Caught all 9 planted events, matched all 22 verdicts, and gave identical output across 3 cold runs.
Built with
  • Python
  • pandas
  • ChromaDB
  • Groq LLM API
  • pytest
  • Docker

Aegis Risk Engine

Risk-management API for a lender

  • Source code
What
A risk engine for a non-bank lender, built from a case-study brief. It scores loans, calculates RBI provisioning, measures market and operational risk, and prepares regulatory returns.
How
FastAPI services with JWT login and four-eyes approval for credit overrides. Loan batches are read from SFTP and loaded into ClickHouse, all on a Docker Compose stack.
Proof
11 unit tests across the risk engines and access rules. GitHub Actions runs Ruff, Bandit and pytest.
